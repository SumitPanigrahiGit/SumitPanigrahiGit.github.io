Placement Platform

REST API for job postings, signup/login and applications, deployed on AWS.
  • FastAPI, SQLAlchemy, PostgreSQL; JWT auth with bcrypt password hashing
  • Rate limiting on login, signup and pipeline endpoints (HTTP 429)
  • Docker image on EC2; PostgreSQL on RDS in a private network, reachable only from the app's security group
  • Container logs shipped to CloudWatch using an IAM instance role (no stored keys); log retention set to avoid cost
  • Small HTML/JS frontend served by the API

Job Skill Trends

Data pipeline that tracks which skills appear most in remote job postings.
  • EventBridge schedule triggers a Lambda that fetches the Remotive API daily
  • Raw JSON lands in an S3 data lake, partitioned by date
  • Athena queries on top: top skills, top skills per category, rising skills week over week
  • Deduplication view using window functions
